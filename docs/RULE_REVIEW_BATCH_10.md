# 规则审查 Batch 10：探险队领袖起始卡

## 范围与阅读方式

本批审查六位领袖的四张起始卡（共 24 张）。表中“当前引擎实现”描述的是已经接入引擎的效果与门槛，不把它当成已确认的规则。

为避免与 Batch 09 混淆：每张神秘人起始卡下半部的行动是“放逐该起始卡作为成本，以开始仪式”的独立主行动，已放在 Batch 09 的 `mystic-02`；蓝色神像的仪式则直接执行，不需要放逐起始卡。本批只审查这些牌正常打出时的效果。

回复可以按单卡或单行，例如：`captain-piloting OK`、`explorer-hike：第二分支是……`。

## 本批的高优先级确认点

1. 已确认的门槛类牌（包括 Transmission）均为“选择一个已解锁分支”，不累计；其余同类卡请按这个语义审查。
2. Tracking 与 Scouting 已确认均只影响打出当回合的下一次发现；一回合最多发现一次，因此发现后清除。
3. Hike 只能发动营地地点，且零食放在 Hike 牌面上；Cartography 的零食分支是主行动，零食放在 Cartography 牌面上。
4. Blindsight 已确认：正常取得正面神像，但把该神像的奖励替换为放逐自己 1 张牌。
