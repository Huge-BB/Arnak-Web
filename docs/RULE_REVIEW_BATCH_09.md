# 规则审查 Batch 09：探险队领袖版图

## 审查范围与回复方式

这一批只审查 **探险队领袖的个人版图能力**：初始组件、版图上的持续/每轮效果、可点击行动、神像槽、以及与版图直接相连的特殊规则。四张领袖起始卡的完整卡面效果会在卡牌审查中另列；这里仅在它们影响版图状态时提及。

请按编号回复即可，例如：`captain-02 OK`、`mystic-05：应为……`。尚未确认的内容都写成“当前引擎实现”，不是“已通过的规则”。

统一约定：

- 除神秘人外，每位领袖的神像槽为 `1 / 2 / 3 / 4 VP`；第 3、4 槽为蓝色效果槽。
- 领袖起始牌组为四张领袖卡；开局另有两张恐惧。男爵夫人的「惊喜快递」固定在起始手牌，其余起始牌随机组成手牌。
- 普通 `获得恐惧` 进入弃牌堆。神秘人的每轮一张恐惧是明确例外，进入手牌。

## 实作边界（本批确认后再处理）

- 每位领袖版图需要有命名、可校准的透明/发光热区：`leader-{id}-{ability}`，不要让卡面插画本身承担点击语义。
- 需要保留状态可视化：专家是否已用、老鹰位置、惊喜快递是否已武装、教授档案/手提箱、零食是否已用、仪式堆与神秘人槽位状态。
- 本批不把上述文字自动标为“规则已通过”；你确认后，再把通过项写入规则审计表并补齐/校准交互。
